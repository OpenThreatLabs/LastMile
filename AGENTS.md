# LASTMILE — Project & AI Agent Guidelines

LASTMILE is an essential healthcare continuity platform designed for disaster response, war zones, and public health crises. It models complex healthcare dependencies (supplies, power, staff, transport), simulates cascading infrastructure failures, and computes optimal resource reallocations.

## 🏗️ 3. Tech Stack & Architectural Conventions

- **Frontend:** Next.js (App Router, React 19, TypeScript), Tailwind CSS v4.
- **Backend / Algorithmic Engine:** Python / FastAPI, NetworkX / OR-Tools (for graph flow & dependency cascades).
- **Core Principles:**
  - **Deterministic Optimization over Hallucinated AI:** The Healthcare Continuity Score (HCS) and resource allocation decisions must rely on graph/constraint-satisfaction algorithms, not black-box LLM estimations.
  - **Type Safety:** Strict TypeScript everywhere. Do not use `any` for domain models (Hospitals, Routes, Resources, FailureEvents).
  - **Component Structure:**
    - `app/` — Next.js App Router routes and pages.
    - `components/ui/` — Base primitives and shadcn components.
    - `components/modules/` — Domain-specific modules (e.g., `map`, `simulation-controls`, `continuity-meter`, `transfer-table`).
    - `lib/` — Utilities, scoring formulas, API clients, and graph helpers.
    - `types/` — Shared TypeScript interfaces and disaster schemas.

## 🚀 4. Workflow Rules for Contributing Agents
